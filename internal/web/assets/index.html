Settings

Fallback routing

Ordered virtual routes try each target in turn. This timeout bounds how long a stalled target may delay before the next target is tried.

Be careful setting this too low — it must be high enough for the provider to process the request and start responding. We recommend keeping it at least 60 seconds.

Request logging defaults

Copied into each new client key at creation. Changing these never alters existing client keys.
